## 二、 系统性缺陷量化统计（306 份报告 & 1,135 条种子）

1. **输入 CoT 尾部被 `[:700]` 腰斩（影响 `80.4%` 的种子错题），诊断模型只能靠选项猜死因**
   - 在 1,135 条 `bad_cases` 中，**912 条（80.4%）** `_wrong_reasoning` 长度超过 700 字符，**878 条（77.4%）** 超过 800 字符（中位数 **2,522** 字符，最长 **69,328** 字符）。
   - 旧版 `build_batch_diagnosis_prompt` 截断前 700 字符，而前 700 字符绝大多数在复述题干。诊断模型看不到 CoT 结尾真正选错的推理跳转，只能对照“题干 + 标准答案 + 错误选项”写泛化归因。

2. **奇数尾差导致 `batch_size = 1` 单样本过拟合（`21 / 306 = 6.9%`），有效率暴跌至 `1.15%`**
   - 按旧版配额与不放回采样顺序（`[i*2 : i*2+2]`），配额在 [dimension_coverage.json](file:///D:/workspace/pre/rsi/output/tombench-grpo-hard-20261115/_intermediate/diagnosis_reports/ToMBench/dimension_coverage.json) 中原计划为 **460** 份，实际只产出 **306** 份（30 个维度因错题不足被提前 `break` 饥饿截断，丢失 **154** 份配额）。
   - 更严重的是，有 **21 份报告**（索引：`17, 20, 23, 30, 58, 75, 99, 120, 133, 136, 184, 190, 216, 222, 231, 233, 252, 254, 270, 281, 283`）恰好落在该维度最后 1 条奇数尾差错题上（`batch_size=1`）。
   - **下游实测对照**：这 21 份单样本报告生成的 **87 条**合成题中，得分分布为 `{0: 1, 6: 1, 7: 4, 8: 81}`，**仅 `1 / 87 (1.15%)` 落入 `2–6/8`**；而 `batch_size=2` 的 285 份报告产出 **`71 / 1,150 (6.17%)`**，有效率相差 **5.4 倍**。

3. **中文维度报告 97.2% 纯英文输出（`137 / 141`）**
   - 全部 141 份 `_meta.lang == "zh"` 报告中，**137 份（97.2%）** 负载内零汉字、全英文编写；仅 **4 份**（`#168, #175, #231, #290`）使用中文撰写。Stage 3 生成中文题时不得不二次转译英文抽象约束，加剧了语义生硬或错位。

4. **显式的“事后消歧反应”或表层 `gaze/smile` 线索指令**
   - 在核心四字段（`common_error_patterns / failure_trigger / required_distractor_logic / hard_constraints`）中按关键词精确人工核验正反语义后：
     - 共有 **20 份（6.5%）** 提及 `confirm / disambiguate`，其中 **12 份**出现在 `hard_constraints`；进一步区分正反约束：**5 份（`#0, #1, #7, #28, #165`）** 在 `hard_constraints` 中明确要求后续可观察行为或上下文“确认/消歧”隐含意图（典型如 `#0` 要求：*“At least one relevant agent must respond in a way that confirms or disambiguates the implied intention without stating it explicitly”*），**1 份（`#256`）** 要求检查提供消歧数值，而另外 **5 份（`#72, #169, #205, #217, #220`）** 恰相反是**禁止**直接确认或要求省略消歧线索（`#167` 为反衬重复话语非简单确认）。
     - 共有 **15 份（4.9%）** 提及 `gaze / glance / smile / nod / wink`：其中 **12 份（`#0, #1, #7, #47, #58, #62, #102, #170, #220, #221, #222, #253`）** 正向要求或预设了这类高频表层非语言线索（容易诱导 Stage 3 套用“眼神/微笑题眼”模板），而 **3 份（`#60, #217, #218`）** 则是明确**禁止**出现凝视/指点线索（确保指代歧义）。
     - 上述正向“事后行为消歧 / 高频 `gaze/smile` 线索”指令合计涉及 **14 份报告（4.6%）**（`#0, #1, #7, #28, #47, #58, #62, #102, #165, #170, #220, #221, #222, #253`）。

5. **95.8%（`293 / 306`）机械照抄 Prompt Skeleton 中的难度分布**
   - 293 份报告的 `difficulty_distribution` 原封不动照搬模板示例值 `{"easy": 0.2, "medium": 0.5, "hard": 0.3}`（其余仅 13 份有微调）。

6. **源数据集标签错位被 Stage 2 无条件放大（`Belief: Sequence false beliefs` 100% 错标）**
   - 在 `bad_cases.jsonl` 中，全部 **57 条** 标记为 `Belief: Sequence false beliefs`（`33 en + 24 zh`）的样本，其 `meta.filename` **全部来自 `Unexpected-Outcome-Test.jsonl`**（意外结果情绪反常归因题，而非连续错误信念）。
   - Stage 2 未对维度名与输入题型进行一致性校验，致使该维度下 **19 份报告**（`#153–#163`, `#297–#304`）中有 **10 份**直接把 `primary_cognitive_operation` 判成 `emotion_attribution`，强迫 Stage 3 用情绪惊讶的规则去生成“连续错误信念”维度题。

#### 案例 C-2（同一因果链强制拆出“两个真命题”）：`Report #268` $\rightarrow$ `synthetic_tombench_268_2_0` (`0/8`)

- **诊断谬误**：在 `sample_idx=5034 / 5042` 中，李明“忘记带走球，以为在包里”，答案选“忘记事件”，干扰项是“认为在包里”——原题本身就存在“近因（认知状态）vs 远因（遗忘行为）”的逻辑重叠。`Report #268` 不仅没有提示消解该重叠，反而在 `hard_constraints` 明确要求：**必须以遗忘行为为正解、以错误信念描述为干扰项**（`The correct explanation must be the causal memory or action failure, not merely the resulting belief state. At least one distractor must describe the false belief`）。
- **下游 `0/8`**：`synthetic_tombench_268_2_0` 严格照做后，正解是“周岚签快递时把充电器搁在鞋柜忘了装袋”，错解是“周岚认为相机充电器此刻就装在蓝背包侧袋里，于是照自己的认识告诉了赵磊”——两句皆为故事里的真陈述，模型全部按直接说话动机选了后者（`0/8`）。

#### 案例 C-3 / B（单向剧透指令 vs 视角边界遗漏）：`Report #0`, `#41`, `#218`

- **剧透模板（Report #0 / #41）**：`Report #0`（与同维度的 `#1` 相比，输入 CoT 均逾 2,200 字符且被截断）给出了笼统的“字面意义 vs 隐含请求”并外加“必须有同伴事后反应来确认意图”，导致下游 8 题得分 `7, 8×7`；`Report #41` 直接照搬 1-hop 单盒标签错位结构，导致下游 8 题全部 `8/8`。

#### 案例 A（标杆高质量报告的共同特征）：`Report #1`, `#60`, `#148`, `#177`

高质量报告都有一个共同特点：**绝不抄录单题表面道具或语言文字游戏，而是精准锁定至少包含三要素的“结构性视角隔离 / 评估冲突”**：
